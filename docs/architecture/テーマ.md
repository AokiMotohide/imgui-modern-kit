# テーマとカスタマイズ

[English](themes.md) · [目次](../目次.md) · [デザインシステム](デザインシステム.md) · [自分の世界観を作る](世界観を作る.md)

ImKit は、13種類の洗練された名前付きプリセットと、柔軟なカスタマイズ API を提供しています。

---

## 組み込みプリセット一覧

`ThemePresets()` を呼び出すことで、全13種類のプリセット情報を取得できます。各プリセットには enum 値、永続化用の小文字 ID（例: `"precision-dark"`）、表示名が定義されています。

`PrecisionLight`、`PrecisionDark`、`Slate`、高コントラストの2種は、手で調整した配色です。それ以外の8種（Graphite、Midnight、Ocean、Forest、Violet、WarmSand、Rose、Solar）は、背景・面・文字・アクセントの4色から `MakeBrandTheme` で作っています。ホストが自分のテーマを作るときと同じ関数の使用例にもなります。手順は [自分の世界観を作る](世界観を作る.md) を参照してください。

| カラースキーム | プリセット名 | 特徴 |
|---|---|---|
| **Dark** | `PrecisionDark` | ImKit の標準ダークテーマ。落ち着いたグレーとブルーのアクセント |
| | `Graphite` | 黒に近い深いグレーの地にミントグリーン |
| | `Midnight` | 深夜のネイビーの地にラベンダーブルー |
| | `Ocean` | 深い青緑の地にシアン |
| | `Forest` | 深い森の緑の地にグリーン |
| | `Violet` | 濃い紫の地にパープル |
| | `Slate` | 青灰色の背景・面を持つ専用配色 |
| | `HighContrastDark` | コントラスト比を高めた視認性重視のダークテーマ |
| **Light** | `PrecisionLight` | ImKit の標準ライトテーマ。クリーンな白と淡いグレー |
| | `WarmSand` | 砂色（サンドベージュ）の地にブラウン |
| | `Rose` | 淡いピンクの地にローズ |
| | `Solar` | 日だまりのような暖色の地にオリーブゴールド |
| | `HighContrastLight` | 視認性重視の高コントラストライトテーマ |

## コード例: テーマの選択と復元

設定ファイルへ保存する際は、enum の整数値ではなく「安定した小文字 ID」を保存することを推奨します：

```cpp
#include <imkit/theme.h>

// 1. プリセットから直接生成
auto theme = imkit::MakeTheme(imkit::ThemePreset::Forest);

// 2. 保存されていた文字列IDから安全に復元（フォールバック付き）
std::string savedId = "graphite";
auto preset = imkit::ThemePresetFromId(savedId)
    .value_or(imkit::ThemePreset::PrecisionDark);
auto currentTheme = imkit::MakeTheme(preset);
```

## 配色のカスタマイズ (`SetAccent`)

ブランドカラーやプロジェクトのテーマカラーに合わせて、アクセント色を一括変更できます：

```cpp
// アクセントカラーをオレンジに変更
// ※ ボタン背景、フォーカス枠、選択ハイライトなどが連動して更新されます
imkit::SetAccent(theme, ImVec4(1.0f, 0.5f, 0.0f, 1.0f));
```

さらに細かい配色を調整したい場合は、`theme.semantic.*` の各フィールドを編集し、`imkit::ResolveTheme(theme)` を呼び出します。`semantic`（および `typography`、`radius`、`stroke`、`elevation`、`opacity`）が正で、`theme.colors` と `theme.metrics` は `ResolveTheme` が作る派生値です。`colors` を直接編集しても、次の `ResolveTheme` や `SetDensity` で上書きされます。

## スケール倍率と `ThemeScope`

- **スケール倍率**: `ApplyTheme(theme, scale)` の `scale` 引数により、UI 全体の表示倍率を 50%～250%（既定: 125%）の範囲で調整可能です。未拡大の元トークンから毎回スタイルを再計算するため、毎フレーム呼び出してもサイズが累積することはありません。
- **部分的なテーマ適用**: 一部のダイアログやパネルだけに異なるテーマを適用したい場合は `imkit::ThemeScope` を利用します。
