# デザインシステム

[English](design-system.md) · [テーマ](テーマ.md) · [文書カタログ](../reference/文書カタログ.md)

ImKit のデザインシステムは、Dear ImGui 上に構築される制作ツール向けに最適化された、統一されたデザイントークン、アクセシビリティ仕様、UIパターンの体系です。

---

## コア設計思想

ImKit のデザインシステムは以下の3本柱で成り立っています：

- **セマンティックトークン中心**: 生のカラーコード（Hex）ではなく、「アクセント」「地色」「境界線」「無効状態」といった役割（セマンティクス）に基づいてスタイルを定義します。
- **ホスト主導のプロバイダ契約**: データのソート、フィルタリング、仮想スクロールのインデックス計算などはすべてホストが管理し、ImKit は描画と入力検出に徹します。
- **アクセシビリティ（a11y）連携**: スクリーンリーダーやキーボード操作に必要なセマンティクス情報を、ホスト所有の `AccessibilityFrame` を通じてOSアダプタへ公開します。

---

## デザイントークンとテーマ API

### テーマの生成 (`MakeTheme`)

```cpp
#include <imkit/theme.h>

// カラースキーム、コントラスト、密度（Density）を指定してテーマを生成
auto theme = imkit::MakeTheme(
    imkit::ColorScheme::Dark,
    imkit::ContrastLevel::Standard,
    imkit::Density::Regular
);
```

- **密度（Density）の変更**: `Compact`（情報密度を高めたいエディタ向け）や `Spacious`（タッチや見やすさ重視）を切り替えることで、文字サイズを維持したままコントロールのパディングや間隔を調整できます。
- **セマンティックトークンのカスタマイズ**:
  ```cpp
  theme.semantic.accent = ImVec4(0.2f, 0.6f, 1.0f, 1.0f); // ブランドカラーの変更
  imkit::ResolveTheme(theme); // トークン変更後に描画用パレット/メトリクスを再計算
  ```

## セマンティックカラーの構成

| トークン名 | 役割・用途 |
|---|---|
| `canvas` | アプリケーションの最背面背景色 |
| `surface` | 通常のパネルやウィンドウの背景色 |
| `surfaceRaised` | カードやポップアップなど、浮き上がった領域の背景色 |
| `accent` | プライマリアクション、アクティブ選択、ハイライトの基調色 |
| `text` / `textMuted` | 主要な本文テキスト / 補足・無効状態の控えめなテキスト |
| `border` / `borderFocused` | 境界線 / キーボードフォーカス時の強調境界線 |
| `destructive` / `warning` / `success` | 危険操作（削除等） / 警告・注意 / 成功・完了状態の通知色 |

## アクセシビリティとローカライズ

- **`AccessibilityFrame`**: UIツリーの各要素に役割（Button、Toggle、Slider等）とラベルを付与し、OSのアクセシビリティAPI（Windows UI Automation / macOS NSAccessibility）へ通知します。
- **`motion.reducedMotion`**: システムの「視覚効果を減らす」設定に応じて、アニメーション遷移時間を0に短縮し即時反映します。
- **`LocaleContext`**: 言語翻訳、数値・日時のフォーマット、レイアウト方向（LTR/RTL）をホスト側のコールバックを通じて適用します。
