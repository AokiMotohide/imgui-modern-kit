# 依存関係

[English](dependencies.md) · [目次](../目次.md) · [文書カタログ](../reference/文書カタログ.md)

本ドキュメントでは、ImKit の外部ライブラリ依存関係、固定リビジョン、および CMake による解決方針をまとめます。

---

## 固定外部依存

| ライブラリ | バージョン / 固定コミット | 用途と制約 |
|---|---|---|
| **Dear ImGui** | 1.93.0 WIP docking<br>`367b2c24f399988ddafc0bb4628da0106bcc09be` | 公開ウィジェット API および型定義。<br>ホスト側との厳密な ABI 一致が必要です。 |
| **GLFW** | 3.5.1<br>`d9d6f0f1f967807ffade6598ea9a631ebaf37a56` | Gallery サンプルのウィンドウ生成、入力、OpenGL コンテキスト管理。 |

> [!NOTE]
> 各ライブラリのライセンス全文およびハッシュ値はリポジトリ直下の [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) に記載されています。

## 依存関係の解決方針

- **サブディレクトリ導入（推奨）**:
  - 既存の CMake プロジェクトへ `add_subdirectory` で組み込む場合、ホスト側ですでにビルド設定された Dear ImGui ターゲットを `IMKIT_IMGUI_TARGET` に渡します。この場合、ImKit が外部リポジトリを自動ダウンロードすることはありません。
- **単体ビルド（Standalone）**:
  - Gallery を含めて ImKit 単体でビルドする場合、`IMKIT_IMGUI_TARGET` が未指定であれば CMake が自動的に上記固定コミットの Dear ImGui と GLFW を取得します。
- **グラフィックスライブラリ**:
  - Windows 向け Gallery は CMake の `FindOpenGL` を使用します。
  - macOS 向け Gallery は システム標準の Metal、MetalKit、Cocoa フレームワークを使用します。

### フォント資産の扱い

Inter 4.1 および Noto Sans JP 2.004 は、ImKit が推奨するオプショナルのフォント資産です（SIL Open Font License 1.1）。
`imkit_copy_font_assets` ヘルパー関数はビルド出力ディレクトリへフォントファイルをコピーするだけであり、フォントのメモリ読み込み、アトラス登録、テクスチャ破棄はすべてホストアプリケーション側で行います。
