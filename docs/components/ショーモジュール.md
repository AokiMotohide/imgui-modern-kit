# Showモジュール

[English](show.md) · [文書一覧](../README.md)

`imkit::show`は、メディアサーバー、VJツール、ショーコントロール向けの任意ターゲットです。`imkit::show`をリンクし（タイムコード用に`imkit::editor_core`も付いてきます）、`imkit/show.h`をincludeします。`imkit/imkit.h`には含まれません。どの部品も描画と入力の報告だけを行います。値、時計、機器、ファイル、保存はホストが持ちます。ライブラリはシステム時計やタイムゾーンDBを読まず、MIDI/OSC/DMXを開かず、スクリプトを解析も実行もしません。

## 共通の約束

| 約束 | 内容 |
|---|---|
| 描画と要求 | 部品は描画し、ユーザーの要求（`ValueEdit`、要求構造体、編集バッファ）を返します。適用はホストが行います。 |
| 連続値 | `ValueEdit{started, changed, finished, cancelled, original, value}`。クリックは1フレームで started・changed・finished になります。ドラッグ中のEscapeは元の値に戻し`cancelled`を立てます。Undoのまとめ、OSC出力の間引き、MIDI Learnに使えます。 |
| 有限の編集 | `RuleEditBuffer`と`StepEditBuffer`は固定容量で、あふれたことを報告します。 |
| 時刻 | `std::int64_t`のUTC秒。`TimeZone`はUTCからの東向き秒数を返すコールバックで、夏時間のデータはホストのものです。 |
| 色 | テーマの意味トークンから導きます（`MakeShowColors`）。13プリセット、ハイコントラスト、全密度で動きます。 |
| 状態 | 色だけで伝えません。パッド、ランプ、キュー行は形か文字を添えます。 |
| アクセシビリティ | フェーダー、ノブ、XYパッド、範囲のつまみは範囲とIncrement/Decrementを持つ`Slider`ノード、メーターは`Meter`ノードです。 |

## 使い方

```cpp
float gain = -6;
imkit::show::FaderOptions fo;
fo.scale = imkit::show::FaderScale::Decibel;
fo.minimum = -60;
fo.maximum = 6;
const auto edit = imkit::show::Fader("Layer 1", &gain, fo, {&theme, &animation});
if (edit.changed) osc.Send("/layer1/gain", gain);   // finished になるまで送信を間引く。
if (edit.finished) undo.Commit();                   // 1回のドラッグを1回のUndoに。
```

```cpp
imkit::show::RuleDocument rule;                      // 自前のモデルがあれば RuleEdit を自分で適用する。
std::array<imkit::show::RuleEdit, 32> storage{};
imkit::show::RuleEditBuffer edits(storage);
imkit::show::RuleBuilder("rule", rule.View(), context, builderState, edits, {}, options);
rule.ApplyAll(edits.Edits(), context);
const auto outcome = imkit::show::EvaluateRule(rule.View(), context, lookup);   // 試し評価。何も実行しない。
```

```cpp
const auto r = imkit::show::Calendar("calendar", events, calendarState, {.zone = zone, .now = now}, options);
if (r.move) host.MoveEvent(r.move, r.start);         // 長さは変わらない。
if (r.create) host.CreateEvent(r.start, r.end);
```

```cpp
const auto r = imkit::show::ScriptPastePanel("script", text, sizeof text, analysis, pasteState, {.now = now}, options);
if (r.analyze) worker.Analyse(text);                 // 次のフレームで診断と検出パラメータを返す。
if (r.import) host.Import(text);
```

```cpp
std::vector<imkit::show::SurfaceItem> items = host.SurfaceItems();   // ホストが持つ配置モデル。
const auto r = imkit::show::ControlSurface("console", items, surfaceState, {.columns = 24, .rows = 12}, options);
if (r.layout.finished) host.CommitLayout();                            // 変更中は r.layout.items[0..count) を適用します。
if (r.removeSelected) host.RemoveSelected(surfaceState);
if (r.add) host.AddItem(r.addKind, r.addAt);                           // SurfacePaletteからのドロップ。
```

```cpp
const auto r = imkit::show::ImageButton("key1", {.image = texture, .imagePixels = {256, 256}, .label = "Intro"}, {.editable = true}, options);
if (r.chooseImage) host.OpenFileDialog(key1);        // ファイルの読込とテクスチャ作成はホストです。
if (r.clearImage) host.ClearPicture(key1);
if (r.pressed) host.Trigger(key1);
```

## 動作の注意

- **Gallery。** ページ25〜33が全部品を疑似データ（キュー、ランチャー、ミキサー、ルール、競合のあるスケジュール、デッキ、貼り付けたシェーダー）で見せます。ここではGalleryがホストで、時計を読み、要求を適用します。
- **ルール。** 空の`All`と`None`は真、空の`Any`は偽です。値が無い変数は偽として数え、`missingVariable`を立てます。文字の`Contains`と`StartsWith`は英字の大小を区別せず、`Equals`は完全一致です。開始が終了より後の時刻範囲は日付をまたぎます。
- **繰り返し。** 該当日が無い月（31日）と、うるう年でない2月29日は飛ばします。春の「存在しない時刻」は欠けた時間だけ進め、秋の「重なる時刻」は最初の方を使います。除外日も`COUNT`に数えます。
- **cron。** 日と曜日の両方を指定した場合は、どちらかに合えば実行します（従来のcronと同じ）。
- **日の出・日没。** `SolarEvents`はNOAA/Meeusの近似で、誤差は数分です。白夜・極夜は`valid == false`を返します。
- **スクリプト貼り付け。** Dear ImGui標準の複数行編集とIMEを使います。内容に合わせて高さが伸び、親のスクロールで動くため、非常に長い文章ではカーソルへ自動スクロールしません。エラーがあっても、`allowImportWithErrors`がtrueなら「Import anyway」で取り込めます（止めずに警告します）。
- **サーフェス。** サーフェスは描画と報告だけを行います。移動とサイズ変更は、スナップ済みの矩形（`layout.items`）と`started/changed/finished/cancelled`の段階で届き、適用はホストが行います。編集モードでは実際のコントロールを止め、選択枠・ハンドル・整列ガイドを重ねます。矢印キーはスナップ幅だけ動かし（Shiftで1セル）、Deleteで削除、Ctrl+Dで複製、Ctrl+Aで全選択、Escapeでジェスチャを取り消します。ロックされた項目は動きません。選択は最大32項目です。
- **画像。** ライブラリはファイルを読まず、テクスチャも持ちません。OSのファイルのドロップはバックエンドのイベントなので、どのボタンのものかは`ImageButtonRequest::hovered`で決めます。アプリ内のドラッグはImGuiのペイロード（`dropPayload`）です。ライブラリはテクスチャの画素を読めないため、アルファの当たり判定はコールバックで行います。
- **LED部品。** `AddressMap`と`FindOverlaps`はDMXアドレスと同じく1始まりのスロットとして扱い、重なりは斜線・印・件数で示します。`EstimateLedCurrent`の画素あたりの電流はホストが与えます（データシートで異なります）。`KelvinToRgb`は1667〜25000 Kを扱います。`PixelPreview`は1回の呼び出しで約1万画素まで描き、配線の重ね描きは2000画素までです。
- **対象外。** 実機のMIDI/OSC/DMX/NDI、OSのタイムゾーンDB、メディア再生、音声解析はホストの責任です。
