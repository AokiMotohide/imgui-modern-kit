# チャート

[English](charts.md) · [文書一覧](../README.md)

`imkit/charts.h`または`imkit/imkit.h`をincludeします。チャート部品はホストが持つ値を描画するだけです。参照だけを受け取り、フレーム間で何も保持せず、メモリ確保も行いません。グローバルなregistry、worker、永続化は導入せず、既存APIも変更していません。

| 部品 | 用途 | 戻り値 |
|---|---|---|
| `DonutChart` | 全体に対する割合。中心に主値、任意で凡例 | クリックされたセグメントの番号。なければ`-1` |
| `BarChart` | 少数の値の比較。縦・横 | クリックされたバーの番号。なければ`-1` |
| `Gauge` | 上限のある1つの値を240°のリングで表示。色の区間つき | なし |
| `Sparkline` | 1系列の傾向。ホバーで値を表示 | なし |
| `CircularProgress` | 進捗リング（[ワークフローコンポーネント](ワークフローコンポーネント.md)）。ドーナツと同じ形状を共有 | なし |

```cpp
const std::array<imkit::ChartDatum, 3> usage{{{"Render", 42}, {"Cache", 24}, {"Other", 6}}};
imkit::DonutChartView view;
view.segments = usage;
view.value = "72 GB";   // 描画中のフレームだけ有効な参照です。
view.caption = "使用中";
const int clicked = imkit::DonutChart("storage", view, {}, {&theme, &animation});
if (clicked >= 0) { /* クリックの意味はホストが決めます。 */ }
```

## 設計の方針

- **色だけで伝えません。** セグメントとバーにはラベルがあり、凡例とツールチップでも示します。`ChartColor(theme, index)`は色覚の多様性に配慮した並びを返し、先頭はテーマのアクセント色です。`ChartDatum::color`のアルファを0より大きくすると上書きできます。
- **カテゴリは少なく。** ドーナツは5分割までが読みやすい目安です。残りはホスト側で「その他」にまとめてください。
- **誠実な軸。** バーは0から始まります。`BarChartOptions::maximum`で軸の上限を固定でき、0なら丸めた上限をデータから求めます。
- **取得不能は0ではありません。** `Gauge`と`CircularProgress`は、負の値や有限でない値を、ダッシュ付きの未取得リングとして描きます。
- **動きはテーマに従います。** `ComponentOptions::animation`を渡し、`Theme::motion`が許す場合に値の変化を補間します。モーション低減では最終状態をすぐに描きます。

## アクセシビリティと制限

`ComponentOptions::accessibility`を渡すと、チャートごとに1つの意味ノード（`Group`。`Gauge`は`Progress`）を公開します。セグメントごとの移動は公開しません。正確な値が必要な利用者には、元の数値を表やテキストでも示してください。負の値と有限でない値は無視します。`Sparkline`は最大256点を描きます。文字はホストのフォントで描き、右から左への配置には対応していません。

Galleryの**Charts**ページに、アニメーションするサンプルデータで全部品を表示します。これはカタログ上のキャプチャであり、スクリーンリーダーやOS統合の動作を保証するものではありません。
