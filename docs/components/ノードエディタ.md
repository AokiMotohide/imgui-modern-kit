# ノードエディタコンポーネント

[English](node-editor.md) · [目次](../目次.md) · [ノードエディタの作成](../tutorials/ノードエディタの作成.md)

`imkit::node_editor`（ヘッダー: `<imkit/node_editor.h>`）は、Dear ImGui 上に構築されるノードベースUIライブラリです。
グラフモデルの評価、Undo/Redo、シリアライズ、永続化はすべてホストが所有し、ImKit はスナップショットの描画と編集リクエスト（`EditRequest`）の報告のみを担います。

## 最初のフレーム描画 (First frame)

ノードエディタの基本的な描画ループです：

```cpp
#include <imkit/node_editor.h>

namespace ne = imkit::node_editor;

void DrawNodeEditor(const ne::GraphView& graph, ne::EditorState& state, ne::RequestBuffer& requests) {
    if (ne::BeginEditor("MaterialEditor", graph, state, requests)) {
        ne::DrawLinks(graph);
        ne::DrawNodes(graph);
        ne::EndEditor();
    }
}
```

- `BeginEditor()`: キャンバスの準備と座標変換の設定（戻り値に関わらず `EndEditor()` は必須です）。
- `DrawLinks()`: ノード間のベジェ曲線の描画。
- `DrawNodes()`: 各ノードの矩形、ソケット行、コントロールの描画。
- `EndEditor()`: スコープの終了と未完了ドラッグの確定。

## ImGui コンテキスト不要の純粋レイアウト (Layout without an ImGui context)

`<imkit/node_layout.h>` は、Dear ImGui Context や GPU レンダラーを一切必要としない純粋な幾何計算APIを提供します：

```cpp
#include <imkit/node_layout.h>

// ヘッドレス環境でのノードサイズ・ソケット位置の計算
ne::NodeMetrics metrics;
auto layout = ne::ComputeNodeLayout(nodeView, metrics);
```

- CIパイプラインやユニットテストで、グラフィックス環境なしにノード配置やソケット座標のテストが可能です。
- 不正なサイズや非有限な数値（NaN / Inf）は安全にバリデーションされます。

## 編集ジェスチャとホスト連携 (Editing and host integration)

ユーザー操作はすべて型付きの `EditRequest` としてホストへ通知されます：

- **ノード移動**: ドラッグ中は一時的なプレビュー座標が返され、マウスを離した時点で `Commit` リクエストが発行されます。
- **リンク作成**: 出力ピンからドラッグし、互換性のある入力ピン上でドロップすると `CreateLink` リクエストが発行されます。
- **削除**: 選択されたノードやリンクの削除キー押下により `DeleteSelection` が発行されます。
- **リビジョン検証**: リクエストに含まれる `revision` 番号と現在のモデルのリビジョンが一致する場合のみ変更を確定します。

## プレビュー・カスタマイズ・対話操作 (Preview, customization and interaction)

- **ノードプレビュー**: `ne::Preview` を呼び出すことで、ノード内にテクスチャサムネイルやカラーグラデーションを表示できます。
- **ノードパレット**: Tabキーや右クリックで `NodePalette` を開き、新規ノードの追加候補一覧を提示できます。
- **選択枠**: 矩形選択（ラバーバンドセレクション）による複数ノードの一括選択をサポートします。

## 開発用デモと検証 (Development demo and checks)

独立したデモアプリケーション（`imkit_node_editor_gallery`）で動作を確認できます：

```powershell
cmake --build --preset windows-debug --target imkit_node_editor_gallery --parallel
./build/windows-debug/catalog/Debug/imkit_node_editor_gallery.exe
```

公開API一覧は [node-editor-api.json](../reference/node-editor-api.json) に記録されています。

## 動的ソケットと標準行レイアウト (Dynamic sockets and standard rows)

- 実行時にピン数が増減する動的ソケット（配列入力など）をサポートします。
- ソケット行にはアイコン、ラベル、インライン編集コントロール（Float入力やカラープレビュー）を混在配置できます。

## Material Graph Mock の検証 (Material Graph Mock)

Gallery に同梱されている Material Graph サンプルは、PBRシェーダー風のノードネットワーク（Texture、Multiply、PBR Output等）を再現した実装例です。ホスト側のデータフローとUndo履歴の設計パターンを学習できます。

## ナビゲーションと外観 (Navigation and appearance)

- 中マウスボタンドラッグまたは右ドラッグによるキャンバスの無限パン操作。
- マウスホイールによるカーソル位置を中心としたスムーズなズームイン・ズームアウト。
- ミニマップ機能によるグラフ全体の俯瞰と素早い視点ジャンプ。
