# 利用ガイド

[English](guide.md) · [目次](../目次.md) · [導入ガイド](導入ガイド.md)

本ガイドでは、ImKit のコア設計思想、Themeの適用ルール、提供される主要コンポーネント、およびアニメーション状態の管理方法について解説します。

## 所有権と拡張レイヤー

`imkit::imkit` は C++20 静的ライブラリターゲットです。
Dear ImGui 本体、Context、`NewFrame` / `Render` の呼び出し、バックエンド（GLFW/OpenGL/DirectX/Metal等）、OSウィンドウ、フォントテクスチャ、および編集対象のデータ値はすべて**ホストアプリケーション**が所有します。

ImKit の関数は、**現在アクティブな Dear ImGui Context の GUI スレッド**から呼び出してください。ImKit は Dear ImGui の標準的な `Begin` / `End` 契約や入力ハンドリング仕様を忠実に維持しています。

- `<imkit/theme.h>`: コピー可能なセマンティックトークン定義。
- `<imkit/native.h>`: Dear ImGui 標準ウィジェットの拡張オーバーロード群。
- `<imkit/widgets.h>`: タブ下線装飾や選択ハイライトを含む互換ラッパー。
- `<imkit/components.h>`: ボタン、トグル、バッジ、セグメントコントロールなどの複合UI部品。

隠れたグローバルレジストリやシングルトン、バックグラウンドワーカー、プラグインマネージャーは一切導入していません。状態は明示的に引数として渡し、データの変更・永続化はホスト側に委ねられます。

## テーマ・フォント・表示スケール

ImKit では、洗練されたモダンUIスタイルをワンストップで生成できます：

```cpp
#include <imkit/imkit.h>

// 1. デザインプリセット（Dark / Light）からテーマを生成
auto theme = imkit::MakeTheme(imkit::ThemePreset::PrecisionDark);

// 2. ホスト側で読み込んだフォントポインタを割り当て（借用ポインタ）
theme.fonts = {regularFont, boldFont};

// 3. 毎フレーム NewFrame() の直前に適用
imkit::ApplyTheme(theme, 1.25f); // スケール倍率（既定: 125%、推奨範囲: 50%～250%）
ImGui::NewFrame();
```

> [!TIP]
> `ApplyTheme(theme, scale)` は元の未拡大トークンからスタイルを再計算して生成するため、毎フレーム呼び出しても倍率が累積することはありません。

ウィンドウの一部や特定のダイアログだけに異なるテーマや倍率を適用したい場合は、`imkit::ThemeScope` を使用します：

```cpp
{
    // スコープ開始: このブロック内だけ一時的に Light テーマを適用
    imkit::ThemeScope scope(lightTheme, 1.0f);

    if (imkit::Begin("プレビュー設定")) {
        imkit::TextUnformatted("このウィンドウ内は Light テーマで描画されます");
    }
    imkit::End();
} // スコープ終了時に直前のスタイルとフォントが自動復元されます
```

> [!CAUTION]
> `ThemeScope` は生成した Context と同じ Context 上で破棄される必要があります。Context 自体の破棄よりも前に破棄してください。

## コンポーネント

ImKit で提供される主な拡張コンポーネントと動作仕様です：

| コンポーネント | 概要・動作仕様 |
|---|---|
| `ActionButton` | Primary / Secondary / Ghost / Destructive の4種。配色とモーションは `ComponentOptions` で制御 |
| `IconActionButton` | アイコン＋短いラベルのボタンスタイル。無効化理由や操作種別を指定可能 |
| `IconButton` | ツールバーに最適なアイコン単体ボタン（ホバー時のツールチップ対応） |
| `Toggle` / `Switch` | チェックボックスの入力・キーボード操作を維持したモダンなスライドスイッチ |
| `IndeterminateCheckbox` | 未確定状態（Mixed）を持つ3ステートチェックボックス |
| `Segmented` | 複数の選択肢から1つを選ぶタブ風のセグメントコントロール |
| `SearchableCombo` | 絞り込みテキスト入力が可能な検索機能付きコンボボックス |
| `InputScalarWithUnit` | 数値入力欄の右端に単位（px, %, ms 等）をきれいに配置 |
| `DragFloatWithUnit`, `InputVector3WithUnit`, `DragVector3WithUnit` | X/Y/Z の3軸ベクトル入力をコンパクトに表示（幅が狭い場合は縦並び） |
| `BeginSettingRow` / `EndSettingRow` | 設定画面用のラベルとコントロールを綺麗に整列する2列テーブル |
| `StatusBadge` | 稼働状態や警告を色・アイコン・テキストで示すステータスバッジ |
| `NotificationCard` | 画面隅に表示する通知カード（消去リクエストをホストへ返却） |
| `BeginToolbar` / `EndToolbar` | アイコンボタンを整然と並べるツールバーコンテナ |
| `ValidationMessage` | 入力欄の直下に表示するエラー／警告インジケータ |
| `OverlayDecoration` | ポップアップウィンドウの内側にインセット陰影を付与する装飾 |

全ウィジェットの網羅的な一覧は [ウィジェット一覧](../reference/ウィジェット一覧.md)、各Dear ImGui関数との対応は [公開API一覧](../reference/公開API一覧.md) を参照してください。

## アニメーションの寿命管理

ホバー時のハイライト遷移やスイッチの滑らかなアニメーションは `imkit::AnimationState` が担います。

```cpp
// ホスト側でコンテキスト毎にインスタンスを保持
imkit::AnimationState animationState;

// フレーム描画時、コンポーネントオプションとして渡す
imkit::ComponentOptions options{&theme, &animationState};
if (imkit::ActionButton("保存", imkit::ActionVariant::Primary, {}, options)) {
    // 押下アクション
}
```

- **内部スロット**: 固定256スロットで動作し、動的なヒープアロケーションを抑えています。
- **ガベージコレクション**: 120フレーム以上描画されなかった項目のアニメーションキャッシュは自動的に回収されます。
- **即時反映**: アニメーション効果を無効化（オプション省略または `duration = 0`）した場合は、遅延なく即座に状態が反映されます。

## ソースコードによる統合

既存のCMakeプロジェクトに `add_subdirectory` で組み込む場合の推奨手順です：

```cmake
add_library(host_imgui STATIC
    ${IMGUI_SOURCE_DIR}/imgui.cpp
    ${IMGUI_SOURCE_DIR}/imgui_draw.cpp
    ${IMGUI_SOURCE_DIR}/imgui_tables.cpp
    ${IMGUI_SOURCE_DIR}/imgui_widgets.cpp)
target_include_directories(host_imgui PUBLIC ${IMGUI_SOURCE_DIR})
set(IMKIT_IMGUI_TARGET host_imgui)
add_subdirectory(external/imgui-modern-kit)
target_link_libraries(your_app PRIVATE imkit::imkit)
```

Dear ImGui は固定された docking コミット `367b2c24f399988ddafc0bb4628da0106bcc09be` を使用してください。

## インストール版SDK

事前ビルドされたSDKパッケージを利用する場合は、`find_package` を使用します：

```cmake
set(IMKIT_IMGUI_TARGET host_imgui)
set(IMKIT_SDK_ABI_CONFIRMED ON) # マニフェストと設定の照合後に指定
find_package(imkit 3.1 CONFIG REQUIRED)
target_link_libraries(your_app PRIVATE imkit::imkit)
```

バイナリ設定（CRT、コンパイラ、ABIフラグ）が完全一致しない場合は、ソースコード直接組み込みを選択してください。
