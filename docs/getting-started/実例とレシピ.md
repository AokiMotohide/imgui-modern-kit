## 最小限の組み込みコード例

```cpp
#include <imkit/imkit.h>
#include <imgui.h>

// ホスト側のフレームループ内:
ImGui::NewFrame();

if (imkit::ActionButton("変更を適用", imkit::ActionVariant::Primary)) {
    // ユーザーがボタンを押したときの処理
    hostApp.ApplyChanges();
}

ImGui::Render();
```

詳細なオーバーロード一覧は [公開API一覧](../reference/公開API一覧.md)、依存要件は [依存関係](../architecture/依存関係.md) を参照してください。
また、CMakeによる最小限の組み込みサンプルは [導入ガイド](導入ガイド.md) および [`examples/consumer`](../../examples/consumer/CMakeLists.txt) で確認できます。
