# ウィジェット一覧

[English](widget-inventory.md) · [基本コンポーネント](../components/基本コンポーネント.md) · [公開API一覧](公開API一覧.md)

ImKitで提供されているGUIウィジェット群およびエディタ向け拡張部品の分類一覧です。
最新の型定義や正確な関数シグネチャについては、公開ヘッダー `<imkit/imkit.h>`、`<imkit/workflow.h>`、`<imkit/editor_core.h>` を参照してください。

## 基本ウィジェット一覧

Dear ImGui標準のウィジェット群に、ImKitのデザインシステム「Precision Layers」が適用されます。

| 部品カテゴリ | 実装方針と特徴 | 適用分類 |
|---|---|---|
| 名前付きテーマ | 13種類の組み込みプリセット。安定IDによる永続化に対応（グローバルな自動変更はなし） | テーマプリセット |
| テキスト、リンク、ボタン、チェックボックス、ラジオボタン、コンボ、進行状況バー | 意味トークンに基づく統一スタイル。Dear ImGui標準の動作契約を維持 | 基本 / 選択 |
| ドラッグ、スライダー、数値入力（スカラー・ベクトル・範囲） | 入力・選択・フォーカストークンによる強調。ネイティブな数値精度とパースを維持 | 数値 / 単位 |
| テキスト入力、ヒント、複数行エディタ | ネイティブ入力およびIME契約を維持。バリデーション用の装飾をサポート | 入力 / メディア |
| カラーエディタ、ピッカー、画像ビュー、プロット | テーマのサーフェス・ボーダー・アクセントカラーと調和した描画 | 入力 / メディア |
| ツリー、折りたたみヘッダー、選択可能行、タブ、テーブル | ネイティブ動作。選択されたツリー/行/タブの下線強調、テーマ別テーブル配色 | 階層 / テーブル |
| メニュー、ツールチップ、ポップアップ、モーダル | 浮き出しサーフェス（Raised surface）、多段スタック、インセット陰影 | オーバーレイ / 配置 |
| ウィンドウ、子領域、レイアウト、スクロール、ドッキング | テーマに準拠した枠線・パディング、ホスト主導のレイアウト管理 | オーバーレイ / 配置 |
| トグルスイッチ、三態チェックボックス、セグメントボタン、検索付きコンボ | ネイティブ部品の合成。ホストが状態値を明示的に所有 | 複合コンポーネント |
| 単位付き数値入力、設定行、ステータスバッジ、トースト通知、ツールバー | テーマとフォントメトリクスから自動計算される小型複合コントロール | 複合 / 数値 / オーバーレイ |

> [!NOTE]
> 旧式のカラム補助関数（Column helpers）も利用可能ですが、新規実装にはDear ImGui標準の `Table` APIの利用を推奨します。

## エディタ拡張部品一覧

汎用ワークフローおよび制作ツール向けのエディタ拡張部品です。

- **ワークフロー部品**: ステップナビゲーター、パンくず、フィルターチップ、インスペクターカード、トースト領域、空状態表示、円形プログレスバー、右サイドパネルレイアウトなど（詳細は [ワークフローコンポーネント](../components/ワークフローコンポーネント.md) を参照）。
- **エディタスイート**: タイムライン、カーブエディタ、トランスポート、3Dビューポート、ギズモ、アウトライナー、UVエディタなど（詳細は [エディタスイート](../components/エディタスイート.md) および [エディタAPI](エディタAPI.md) を参照）。

## 部品設計監査の決定事項

ライブラリ開発時の設計監査において検討された候補と、その採用方針（追加・既存再利用・保留・除外）の記録です。

| 候補機能 | 判定 | 理由・方針 |
|---|---|---|
| ステップナビゲーター、ナビゲーションレール、フィルターチップ | 追加 (Add) | ホスト状態とリクエストIDによる疎結合な操作を提供 |
| 通知、プログレスバー、空状態/エラー表示、ツールバー | 拡張 (Extend) | 既存のパターンとトークン体系を活かして拡張 |
| 画像ビューポート、オーバーレイ描画 | 拡張 (Extend) | 共通のCanvas基盤と選択座標系を再利用 |
| プレビュータイル / ストリップ | 追加 (Add) | 借用テクスチャと既存Splitterを組み合わせたマルチプレビュー |
| カード、折りたたみセクション | 追加 (Add) | テーマサーフェスと明示的な開閉状態管理を提供 |
| SettingRow、PropertyGrid、StatusBadge、Skeleton、区切り線 | 既存再利用 (Reuse) | 不要なエイリアスAPIを増やさず、既存の公開APIをそのまま利用 |
| テーブルソート/フィルターヘッダー、行アクション | 既存再利用 (Reuse) | DataTable / TreeDataGrid およびDear ImGui標準Table APIで充足 |
| 仮想リスト / グリッド | 既存再利用 (Reuse) | VirtualList / AssetBrowser のプロバイダー機構で充足 |
| ツリー/リストの並べ替え、汎用ドラッグフィードバック | 保留 (Defer) | ネイティブドラッグ＆ドロップ機能が利用可能。移動契約はホスト側に委ねる |
| 複数選択アクションバー | 追加 (Add) | 選択件数とコマンド一覧の表示に特化 |
| ズームツールバー | 追加 (Add) | 共通の画像ズーム・パン状態を管理 |
| ミニマップ / オーバービュー | 保留 (Defer) | 独立したコンテンツ縮小契約の複雑化を避けるため現段階では見送り |
| ドメインデータ処理、デバイス制御、永続化 | 除外 (Exclude) | UI静的ライブラリの責務境界外。すべてホストアプリケーション側で管理 |
