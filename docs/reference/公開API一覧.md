## 概要と前提環境

本対応表は、Dear ImGui `1.93.0 WIP docking`（コミットリビジョン `367b2c24f399988ddafc0bb4628da0106bcc09be`）を対象として生成されています。

- **シグネチャの完全維持**: ImKitが提供するネイティブエイリアスは、Dear ImGui標準のデフォルト引数、コールバック関数、各種フラグ、および `Begin`/`End` のスコープ規約をそのまま維持します。
- **スタイルの適用**: 各種ウィジェットにImKitのデザインシステム（Precision Layers）を適用するには、事前に `imkit::ApplyTheme` を呼び出す必要があります。非描画ヘルパー関数には独自の外観はありません。
- **検証の考え方**: 表に掲載された各行は、シグネチャのコンパイルおよびリンクテストを通過したことを示します。全APIを個別に手動操作したという意味ではなく、代表カテゴリごとの対話テストと網羅的コンパイル検証を組み合わせて品質を担保しています。
- **セレクション / タブラッパー**: 選択状態やタブのインジケーター描画は、同一フレーム内の公開 `ImDrawList` を通じて下線マーカー等を描画します。余分な内部アイテムの提出（Submit）は行いません。

## ホストとライブラリの責務境界

以下の機能はホストアプリケーション側の責務であり、ImKitの公開対象からは除外（Excluded）されています。

- **コンテキストとフレームループ**: `ImGuiContext` の生成・破棄、`NewFrame` / `Render` の呼び出し。
- **バックエンドとレンダラー**: DirectX / Vulkan / Metal / OpenGL 等の描画初期化およびプラットフォーム入力の仲介。
- **設定と永続化**: `imgui.ini` の保存・読み込み、ウィンドウ位置やレイアウトの管理。
- **デバッグツール**: `ShowDemoWindow`、`ShowMetricsWindow`、`ShowDebugLogWindow` 等のImGui内部デバッグウィンドウ。
- **メモリ管理**: カスタムアロケーターの設定やロガーの管理。

ImKit独自のマクロコンポーネントやワークフローウィジェットについては [利用ガイド](../getting-started/利用ガイド.md) を、既知の制約や検証環境については [検証記録](検証記録.md) を参照してください。
