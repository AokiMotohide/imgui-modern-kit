# 文書カタログ

[English](documentation-catalog.md) · [文書目次](../目次.md)

ImKitの全公開ドキュメントの構成、対象読者、役割、および実装ソースとの対応表です。
各ドキュメントは英語と日本語のペアで提供されており、日本語版のファイル名は日本語で統一されています。

## 概要

ドキュメントは学習段階や目的に応じて5つのカテゴリに分類されています。

1. **導入と基礎 (`getting-started/`)**: ライブラリの導入手順、設計原則、基本概念
2. **チュートリアル (`tutorials/`)**: 具体的な画面や機能の実装手順
3. **アーキテクチャ (`architecture/`)**: 内部設計、デザインシステム、依存関係
4. **コンポーネント (`components/`)**: 各種UI部品の仕様とホスト契約
5. **リファレンス (`reference/`)**: API一覧、検証記録、移行情報、逆引きトラブル解決
