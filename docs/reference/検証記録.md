## Media revision 2 / 映像改訂2（2026-10-05）

### Native operation footage / native操作素材

Windows x64 DebugのGalleryとNode Editorを共有の正規出力でビルドしました。1920×1080・60 Hzで撮った12本の連続素材には、7,857フレームと成功した状態検査38件を記録しています。比較の共有値、作業タブと階層、三軸入力のドラッグ、操作要求の反映、アイコン検索の文字入力と選択、4回のテーマ選択、Loading→Success、Timelineのスクラブ・クリップ移動・再生・停止、ピンの接続とノードのヘッダー移動を確認しました。中ボタンのパンとホイールのズームも記録しました。独立した比較の回帰検証では、キーボード・disabled・style復元・作業画面への要求反映も通りました。元動画と入力ログはGitへ入れません。

### Film and site review / 映像とサイトのレビュー

英語動画を25カットで構成し、動く文字、操作箇所への寄り、マスクによる切り替え、アイコンの展開、オリジナルの128 BPM音楽を組み合わせました。レビューで見つけた見出しの切れ、字幕の重なり、アイコンの詰まり、画面外のテーマ選択、無効なクリップ移動、スクロール先の通知ボタン、移動後のノードの切れ・重なりを修正しました。修正後に時間付き静止画24枚と通常速度のブラウザー全編再生を確認し、映像トラックだけのコピーでも無音の60秒再生を確認しました。素材の長さが足りない場合は、最終フレームを引き延ばさずエラーにします。

完成動画は60.000秒、1920×1080、60 fps・3,600フレーム、H.264／AACステレオ48 kHz、8,557,071 bytes、−16.06 LUFS、−1.84 dBTPです。2段階の音量正規化でAAC復号後のピークに余裕を確保しました。native GIF12本は960×540、20 fps、6〜8秒、すべて2 MiB以下で、最大は1,325,419 bytesです。Pages生成、Astro型チェック、静的build、61ページ・4,182リンクの検査が通りました。ブラウザーでは日英、明暗、PCと約390 CSS pxの幅、動画再生、GIFの再生・停止を確認しました。READMEとPagesのポスターも更新し、Pagesの動画URLには内容ハッシュを付けます。

### Evidence and limits / 証拠と未確認事項

v3.2.0のライブラリタグ、sourceアーカイブ、5構成のSDKアーカイブ、元のrelease CIの識別情報は維持します。改訂映像の制作コミット、更新日時、ハッシュ、証拠はrelease manifestに別途記録します。計測と画面レビューは、音楽の聴感評価、購入者による商用品質の受入、物理OS入力・IME、実機の受入を示しません。今回の素材はWindows OpenGLの開発用撮影であり、配布する全環境でnative操作の受入が済んだとは扱いません。

## ImKit 3.2 release preparation / 3.2公開準備（2026-10-04）

### GalleryとAPI

Windows x64 DebugのGalleryを共有の正規出力でビルドしました。workflow、workflow API compile、toast、toast API compile、theme、native API compile、WindowFrame API compileの7項目が通りました。公開IO操作によるnative検証で、比較の2モード、左右からの入力、キーボード操作、disabled状態、style復元、作業画面の選択・切り替え要求の反映を確認しました。workflowとtoastsの検証も通り、トーストは明暗の6位置、日本語の処理中表示、操作・閉じる要求、同一IDの完了更新を確認しました。640×600のbackbufferで折りたたんだ案内とスクロール可能な設定を確認し、1280×720の実キャプチャからGIFを生成しました。

### 映像と公開サイト

最初の10秒の訴求、時間付き静止画と全編再生、README・Pages・GIF・APIの一致を3段階で確認しました。標準側のフォント条件、比較の独立表示、ラベルの収まり、トースト設定、アイコンの背景、処理完了の表示タイミング、古い文書パスと見出しリンクを修正しました。動画は60.000秒、1920×1080、60 fps・3,600フレーム、H.264／AACステレオ、6,023,496 bytes、−16.00 LUFS、−1.78 dBTPです。12本の `v3-*.gif` は960×540で、すべて2 MiB以下です。最大は1,877,626 bytesです。動画は実UIとオリジナルのモーショングラフィックス・音楽の合成で、文書GIFはnative実キャプチャです。

Pages生成、Astro型チェック（診断なし）、静的build、61ページ・4,182リンクの検査が通りました。Chromeで日英、明暗、PCと約384 CSS pxのモバイル幅、GIFの再生・停止、動画の60秒再生を確認しました。Pagefindでは `DragVector3WithUnit` と `TableGetColumnFlags` が検索できました。最終コミットのCI結果とSDK package consumerの記録は、5構成の成功を確認した後、releaseのmanifestと検証アーカイブへ保存します。ローカルの結果だけでプラットフォームのrelease gateを満たしたとは扱いません。

### 受入の範囲

公開ImGui IOとbackbuffer撮影は、物理OS入力、native IME、実際の読み上げ、複数モニターのDPI、外部製品統合、実機の受入を示しません。Universal 2のテストはarm64のCIホストで実行し、x86_64は別ジョブで確認します。macOSの署名・notarizationはrelease認証情報の有無に依存します。`WindowFrameContent::iconTexture` の追加に対してconsumerの再コンパイルが必要です。Dear ImGuiの対応revisionは変わりません。

## Colored toasts / 色付きトースト（2026-10-01）

Windows x64 Debugで新しいトーストとAPI compileテスト、既存workflowの回帰、外部ホストImGuiを使うトーストconsumerのコンパイルを確認しました。native OpenGL Galleryの `--verify-toasts --output out/toast-verification` でマウスの操作・閉じる要求、Spaceによる操作、同一IDの処理完了を確認し、明暗それぞれ6位置と日本語の進捗不明表示を撮影しました。当時の `docs/images/v3-toasts.gif` はこのGalleryの6位置×明暗のbackbufferから生成した、960×540・96色・12フレームのアニメーションです。移動中も通知カードが鮮明に見えるよう、GIFの各フレームで背景を復元します。ホストのクリック後も通知を表示するため、重なるホストウィンドウに `NoBringToFrontOnFocus` を指定します。この追加に対するnative OS/IME、読み上げ、モニター間DPI、macOS、Arm64、Release、install/packageの受け入れは未実施です。使い方は[トースト](../components/トースト.md)を参照してください。
