# 検証記録

[English evidence log](validation.md) · [アーキテクチャ](../architecture/アーキテクチャ.md) · [文書カタログ](文書カタログ.md)

本ドキュメントは、ImKitの各リリース・マイルストーンにおける検証実績とテスト証拠の記録です。
詳細なテスト実行パラメータ、コミットリビジョン、およびプラットフォーム別マトリクスは [英語版の検証ログ (validation.md)](validation.md) を正本として参照してください。記録された結果は指定された日付・リビジョン・構成において確認されたものであり、後続のチェックアウトや未記載の環境を無条件に保証するものではありません。

## v3.0 platform matrix / v3.0 プラットフォーム構成

2026-09-13時点におけるv3.0 CI実行記録です。各ジョブのHeadコミットSHA、OS、CPUアーキテクチャ、コンパイラ、およびパス結果については英語版を参照してください。

## Node editor access, appearance and collapse / ノードエディタの導線・外観・折りたたみ（2026-09-12）

ノードエディタコンパニオンのUI改修に対する検証記録です。ノードの折りたたみ表示、ポート接続描画、およびギャラリーでの対話操作が確認されています。

## V3 Gallery and documentation captures / v3 Galleryと文書用キャプチャ（2026-09-13）

ギャラリーアプリケーションおよびドキュメント掲載用の自動画像キャプチャに関する記録です。バックバッファやGPUキャプチャの成功は、OSネイティブのIME入力や外部レンダラーとの完全な互換性を直ちに証明するものではありません。

## Timeline external-drop preview / タイムライン外部ドロッププレビュー（2026-09-12）

タイムラインへの外部ドラッグ＆ドロップ時のプレビュー描画およびイベントルーティングの検証記録です。実際のホスト側のデータソース解決、クリップ衝突回避ポリシー、Undo履歴の正当性はホスト側の責務です。

## Preview placement extension / プレビュー配置拡張（2026-09-12）

画像やビューポートプレビューの配置ロジック（Fit / Fill / Stretch）の実装および境界値検証の記録です。

## Public window frame / 公開ウィンドウフレーム（2026-09-11）

カスタムウィンドウ枠（WindowFrame）の描画およびWin32/macOSアダプターの統合テスト記録です。物理高DPIディスプレイや異種DPIマルチモニター環境での挙動は別個の受け入れ検証が必要です。

## Generic workflow extension / 汎用ワークフロー拡張（2026-09-11）

汎用ワークフロー部品（ナビゲーション、トースト通知、カード、プログレスバー等）の画像キャプチャと合成操作テストの記録です。

## Limits / 制約と検証境界

OSネイティブのIME変換、スクリーンリーダー等のアクセシビリティ支援技術、実機マルチDPIモニター間のウィンドウ移動、外部ホストレンダラー（DirectX/Metal等）、実メディアデコード処理、およびコード署名/公証は、個別の実機検証記録がない限り未検証です。シグネチャのコンパイル/リンク、CIビルド、Dear ImGui仮想IOテスト、およびGPUヘッドレスキャプチャはそれぞれ異なる種類の証拠として区別されます。

## Editor Suite 1.0

Editor Suite 1.0は過去のリビジョンにおける検証履歴です。現行のEditor Suite 2.0の契約や現行ブランチの品質保証として再利用するものではありません。

## Dynamic node sockets / 動的ノードソケット（2026-09-12）

実行時にピン数や型が変化する動的ソケットに関する過去の動作確認記録です。グラフモデルの整合性管理、接続可能性ポリシー、リビジョンのコミット判定はホスト側の責務です。

## Node navigation completion / ノードナビゲーション操作（2026-09-12）

ノードエディタのパン・ズーム操作、矩形選択、リンク削除等の操作性検証記録です。最新のAPI仕様や契約については [ノードエディタ](../components/ノードエディタ.md) を参照してください。
