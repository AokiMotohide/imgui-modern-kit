# 検証記録

[English](validation.md) · [アーキテクチャ](../architecture/アーキテクチャ.md) · [文書カタログ](文書カタログ.md)

このページは、どのリビジョン・構成で何を確認し、何を確認していないかを記録します。コンパイル・リンク、公開IOでの操作、GPUの見た目、配布は別の種類の証拠で、互いの代わりにはなりません。結果が成り立つのは、記載した日付・リビジョン・構成だけです。

## 常設の確認項目

Galleryとテストスイートが、リリースのたびに確認します。標準APIの署名確認が通っても、標準APIの全動作を再検証したことにはなりません。

生成する証拠とメディア:

- 公開IOのログは `out/catalog/interaction.txt`、レンダラーの情報は `out/catalog/capture-info.txt` に出ます。どちらも生成物で、コミットしません。

- READMEとPagesのアニメーションは、Galleryを1920×1080・60 Hzで可逆圧縮録画したテイクから切り出します。`tools/media/capture.py` が録画と各テイクの検査を行い、`tools/media/verify.py` がGIFの規格（960×540、2 MiB以下、6〜8秒）と動画の規格を確認します。どちらもnative OS入力の検証ではありません。

## 制約

- 基準: Dear ImGui dockingのコミット `367b2c24f399988ddafc0bb4628da0106bcc09be`、既定のABI型。対応する配布物は、リリースのパッケージ（Windows x64／Arm64、macOS arm64／x86_64、Universal 2）です。それ以外の組み合わせは、ソースビルドと独自の検証が要ります。
- native OS/IME入力、実機、他アプリへの導入は、このrunnerでは検証しません。
- 並べ替え、リサイズ、ドラッグ＆ドロップは、標準のAPIをそのまま使います。その組み合わせの全数は、再実装も再試験もしていません。
- nativeのラッパーは即時です。任意の明示的なアニメーションは、独自の装飾にだけ作用します。フォント、レンダラー、状態の所有はホストが持ちます。
- 入力の単位は、別のラベルです。標準の数値テキストのレイアウトと解析を保ち、ドラッグ・スライダーの標準の中央揃えと、標準のテキスト編集も含みます。
- 日本語の対応範囲は、同梱のフォントに限ります。日本語の見出しはRegularを使い、任意のUnicodeや絵文字の対応は主張しません。
- 操作後のスクリーンショットは、初期値と異なる状態になり得ます。合成した基準画像は、証拠に使いません。
