# カスタムコンポーネントの作成

[English](custom-component.md) · [目次](../目次.md) · [仕組みと設計思想](../getting-started/仕組みと設計思想.md)

ImKit では、ライブラリの内部コードに手を加えることなく、プロジェクト固有のモダンな独自ウィジェット（カスタムコンポーネント）を追加できます。
カスタムコンポーネントの実装は、**`ThemeScope`**、**セマンティックトークン（カラー・メトリクス）**、**ホスト側の状態保持**、そして**操作結果の返却**という4つの原則に従うだけで、公式コンポーネントと全く同一の外観・動作一貫性を実現できます。

![Gallery でのテーマ付きパネル](../images/gallery-overview.gif)

---

## コアパターン（4つの実装原則）

1. **`ThemeScope` でスコープ化する**: コントロールをアクティブなテーマスコープ内で描画し、ブロック終了時に直前のスタイルを自動復元します。
2. **生の色コード（Hex）を使わず、セマンティックトークンを参照する**: `theme.semantic.*` から色を取得することで、Dark / Light の切り替えやハイコントラスト表示に自動追従します。
3. **状態はホストで所有する**: コントロールはモデルが保持する値を読み書きするだけで、ImKit は値を内部保持しません。
4. **自らデータを変えず、操作結果を戻り値で報告する**: 値の変更時に `true` を返すなど、状態更新の決定権をホストに委ねます。

---

## 作成するもの

本チュートリアルでは、カテゴリタグの選択やフィルタリングに便利な「トグルチップ（Filter Chip）」ウィジェットをゼロから作成します：
- テーマのアクセントカラーに応じた選択ハイライト。
- ホバー時・アクティブ時の視覚フィードバック。
- クリックによる選択状態の切り替えとイベント報告。
- オプションとしてのアクセシビリティ注釈の付与。

---

## 必要な環境

1. Dear ImGui コンテキストとウィンドウ。
2. `MakeTheme` または `MakePrecisionTheme` から生成した `Theme` オブジェクト。
3. CMake で `imkit::imkit` ターゲットをリンクした環境（アクセシビリティ注釈を行う場合は `accessibility` もリンク）。

## ホスト側で状態を所有する

```cpp
#include <imkit/imkit.h>

struct ChipState {
    bool isSelected = false;              // 選択中フラグ
    const char* label = "タグ名";          // 表示ラベル
    imkit::StableId id = 1001;           // フォーカス用の一意なID
    bool isDisabled = false;             // 無効化フラグ
};
```

## テーマ適用と描画処理

```cpp
#include <imkit/imkit.h>
#include <imgui.h>

bool DrawChip(const char* label, bool* selected, const imkit::Theme& theme) {
    imkit::ThemeScope scope(theme);

    ImVec4 bgColor = *selected
        ? theme.semantic.accent
        : theme.semantic.surfaceRaised;
    ImVec4 textColor = *selected
        ? theme.semantic.onAccent
        : theme.semantic.text;
    float borderRadius = theme.metrics.radius;

    ImDrawList* drawList = ImGui::GetWindowDrawList();
    ImVec2 pos = ImGui::GetCursorScreenPos();
    ImVec2 textSize = ImGui::CalcTextSize(label);
    ImVec2 padding = {12.0f, 6.0f};
    ImVec2 size = {textSize.x + padding.x * 2.0f, textSize.y + padding.y * 2.0f};

    ImGui::InvisibleButton(label, size);
    bool clicked = ImGui::IsItemClicked();
    bool hovered = ImGui::IsItemHovered();

    if (clicked) {
        *selected = !*selected;
    }

    if (hovered && !*selected) {
        bgColor = theme.semantic.surfaceHovered;
    }

    drawList->AddRectFilled(pos, {pos.x + size.x, pos.y + size.y},
                            ImGui::ColorConvertFloat4ToU32(bgColor), borderRadius);
    drawList->AddText({pos.x + padding.x, pos.y + padding.y},
                      ImGui::ColorConvertFloat4ToU32(textColor), label);

    return clicked;
}
```

## 変更を報告し、直接実行しない

ウィジェットは変更が発生したとき（クリック時など）に `bool` やアクション結果を返します。ホスト側はその戻り値を検知して、フィルタ処理や再描画、Undo履歴の追加などを実行します：

```cpp
static bool isFilterActive = false;
if (DrawChip("オーディオのみ表示", &isFilterActive, currentTheme)) {
    // 状態が変更されたので、ホスト側でリストの再フィルタリングを実行
    UpdateFilterCriteria();
}
```

## 任意: アクセシビリティ注釈

スクリーンリーダーや支援技術に対応する場合、`imkit::accessibility` の注釈APIを追加します：

```cpp
#if defined(IMKIT_WITH_ACCESSIBILITY)
    imkit::accessibility::AnnotateRole(ImGui::GetItemID(), imkit::accessibility::Role::CheckBox);
    imkit::accessibility::AnnotateChecked(ImGui::GetItemID(), *selected);
#endif
```

## 正しい設計を保つための規則

- **`ThemeScope` のスコープ境界を守る**: ウィジェット関数内でスコープを開き、関数を抜ける際に確実に復元されるようにします。
- **生の色リテラルを書かない**: ハードコードされた `ImVec4(1, 0, 0, 1)` のような値を避け、常に `theme.semantic` から参照します。
- **ImGui の ID スタックを活用する**: 複数配置されるウィジェットは `##id` や `PushID`/`PopID` で一意性を確保します。
