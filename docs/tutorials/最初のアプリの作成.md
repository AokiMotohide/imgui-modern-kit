# 最初のアプリの作成

[English](build-first-app.md) · [目次](../目次.md) · [仕組みと設計思想](../getting-started/仕組みと設計思想.md)

本ドキュメントは、ImKit を使ってテーマ適用済みのモダンUIコントロールを描画する最小限のアプリケーションを構築する Codelab です。
GPUや画像ローダーを使わずにCPU単体で動作する最小ホスト（`examples/consumer/main.cpp` 相当）をベースに、初期化から描画までの全体の流れをステップバイステップで理解できます。

![ネイティブ Gallery 概要](../images/gallery-overview.gif)

---

## 作成するもの

以下の責務を持つ最小限の Dear ImGui ホストアプリケーションを作成します：

- Dear ImGui コンテキストの生成と I/O 設定。
- ImKit の `Theme` 値の生成とコンテキストへの適用。
- チャイルドウィンドウ内での ImKit テーマ付きコントロール（トグル、ステータスバッジ、アイコン、アクションボタン）の描画。
- ユーザー操作に対するホスト側のイベント処理（状態変数の更新やボタン押下ハンドリング）。

> [!NOTE]
> すべてのデータとコンテキストはホストアプリケーションが所有します。ImKit は描画とイベントの報告のみを行います。詳細は [仕組みと設計思想](../getting-started/仕組みと設計思想.md) を参照してください。

---

## 前提条件

1. C++20 をサポートするコンパイラ（MSVC 2022、Apple Clang 等）。
2. CMake 3.20 以上。
3. 固定コミット（`367b2c24f399988ddafc0bb4628da0106bcc09be`）の Dear ImGui ソースコード。
4. `imkit::imkit` ターゲットとしてリンクされた ImKit ソースまたは SDK パッケージ。

---

## ステップ 1 — Dear ImGui コンテキストの作成

ImKit は自らコンテキストを生成しません。ホストアプリケーション側で起動時に作成し、終了時に破棄します：

```cpp
#include <imgui.h>
#include <imkit/imkit.h>

int main() {
    // 1. Dear ImGui コンテキストの初期化
    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    auto &io = ImGui::GetIO();
    io.DisplaySize = {640, 480};   // 画面解像度（実アプリではウィンドウバックエンドから取得）
    io.DeltaTime   = 1.0f / 60.0f; // フレーム経過時間
    io.IniFilename = nullptr;      // ini ファイルによる自動保存を無効化（ホストが状態を管理）
    io.Fonts->AddFontDefault();    // デフォルトフォントの追加

    // ...
}
```

---

## ステップ 2 — テーマの作成と適用

テーマを作成し、`ImGui::NewFrame()` の**直前**に `ApplyTheme` を呼び出してコンテキストに適用します：

```cpp
    // 2. テーマの生成
    auto theme = imkit::MakeTheme(imkit::ThemePreset::Ocean);
    theme.metrics.controlHeight = 28.0f; // 必要に応じてカスタマイズ可能

    // 3. NewFrame() の前にテーマを適用
    imkit::ApplyTheme(theme, 1.0f); // スケール倍率（1.0 = 100%）
    ImGui::NewFrame();
```

---

## ステップ 3 — ImKit コントロールの描画

フレーム内でImKitのコンポーネントを描画します。状態変数へのポインタを渡し、戻り値でイベントを検出します：

```cpp
    // ホスト側のデータ（状態変数）
    static bool notificationsEnabled = true;
    static int counter = 0;

    // ウィンドウ領域の定義
    ImGui::SetNextWindowPos({20, 20});
    ImGui::SetNextWindowSize({320, 240});
    if (imkit::Begin("Settings", nullptr, ImGuiWindowFlags_NoResize)) {
        // トグルスイッチ
        imkit::Toggle("通知を有効にする", &notificationsEnabled);

        // ステータスバッジ
        if (notificationsEnabled) {
            imkit::StatusBadge("アクティブ", imkit::StatusKind::Success);
        } else {
            imkit::StatusBadge("無効", imkit::StatusKind::Neutral);
        }

        ImGui::Spacing();

        // アクションボタン（クリックで真を返す）
        if (imkit::ActionButton("カウンター増加", imkit::ActionVariant::Primary)) {
            counter++;
        }
        ImGui::SameLine();
        ImGui::Text("値: %d", counter);
    }
    imkit::End();
```

## 完全なサンプルコード

以下が単一ファイルで完結する最小限の実行可能コードです：

```cpp
#include <cstdio>
#include <imgui.h>
#include <imkit/imkit.h>

int main() {
    // 1. Dear ImGui コンテキストの初期化
    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    auto &io = ImGui::GetIO();
    io.DisplaySize = {640, 480};
    io.DeltaTime   = 1.0f / 60.0f;
    io.IniFilename = nullptr;
    io.Fonts->AddFontDefault();

    // 2. テーマの作成
    auto theme = imkit::MakeTheme(imkit::ThemePreset::Ocean);

    // ホスト側の状態変数
    bool notificationsEnabled = true;
    int counter = 0;

    // 3. 単一フレームの描画実行（CPU smoke test）
    imkit::ApplyTheme(theme, 1.0f);
    ImGui::NewFrame();

    ImGui::SetNextWindowPos({20, 20});
    ImGui::SetNextWindowSize({320, 240});
    if (imkit::Begin("Settings", nullptr, ImGuiWindowFlags_NoResize)) {
        imkit::Toggle("通知を有効にする", &notificationsEnabled);

        if (notificationsEnabled) {
            imkit::StatusBadge("アクティブ", imkit::StatusKind::Success);
        } else {
            imkit::StatusBadge("無効", imkit::StatusKind::Neutral);
        }

        ImGui::Spacing();

        if (imkit::ActionButton("カウンター増加", imkit::ActionVariant::Primary)) {
            counter++;
        }
        ImGui::SameLine();
        ImGui::Text("値: %d", counter);
    }
    imkit::End();

    // 4. レンダリングと描画データの生成
    ImGui::Render();
    auto *drawData = ImGui::GetDrawData();
    std::printf("フレーム描画完了: 頂点数 %d, コマンド数 %d\n",
                drawData->TotalVtxCount, drawData->TotalCmdCount);

    // 5. コンテキストの破棄
    ImGui::DestroyContext();
    return 0;
}
```

2. 上記のコードそのものは `examples/consumer/main.cpp` としてリポジトリに収録されています。ウィンドウバックエンドなしでコンパイルおよび1フレームの描画をテストできる最小構成（CPU smoke app）です。

## 内部動作のまとめ

- `MakeTheme` は独立した値型のテーマ構造体を生成します。
- `ApplyTheme` は現在の Dear ImGui コンテキストの `ImGuiStyle` やカラーテーブルをImKitのトークンに基づいて上書き設定します。
- 各ウィジェット呼び出しは Dear ImGui の標準描画バッファへ頂点データを追加します。
- ホスト側の状態変数（`notificationsEnabled` や `counter`）はホストのメモリ領域にあり、ImKitが保持することはありません。

---

## よくある間違いと対策

- **`ApplyTheme` を `NewFrame` の後に呼んでしまう**: 必ず `ImGui::NewFrame()` の前に呼び出してください。後から呼ぶと現在のフレームのウィジェット描画にスタイルが反映されません。
- **フレーム外でウィジェットを呼ぶ**: `imkit::` のウィジェット呼び出しは、必ず `NewFrame()` と `Render()` の間で行う必要があります。
- **`ThemeScope` の寿命**: `ThemeScope` はそれが作られた Dear ImGui コンテキストが破棄される前にスコープアウトして破棄してください。
