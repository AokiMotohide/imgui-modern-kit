# ImKitの文書

[English](README.md) · [プロジェクトの概要](../README.ja.md) · [変更履歴](../CHANGELOG.md)

ImKitは、Dear ImGuiのアプリ向けに、テーマ、部品、編集用の部品を提供する、C++20の静的ライブラリです。ここにあるページは、すべて英語版と日本語版があり、内容は同じです。各ページの対象読者と元のヘッダーは、[文書カタログ](reference/文書カタログ.md)にまとめています。

## 最初に読む

| 目的 | 読む文書 |
| --- | --- |
| 組み込む前に、ImKitの見た目を確かめたい | [Galleryガイド](getting-started/ギャラリーガイド.md) |
| CMakeプロジェクトに追加して、最初のフレームを描きたい | [導入ガイド](getting-started/導入ガイド.md) |
| フレームの仕組みと、だれが何を持つかを知りたい | [仕組みと設計](getting-started/仕組みと設計思想.md) |
| 手順を追って作りたい | [チュートリアル](#チュートリアル) |
| 機能ごとのヘッダーとターゲットを知りたい | [実例とレシピ](getting-started/実例とレシピ.md) |
| アプリに独自の見た目を与えたい | [テーマ](architecture/テーマ.md)、続けて[自分の世界観を作る](architecture/世界観を作る.md) |
| 以前のバージョンから更新したい | [4.0・4.1への移行](reference/v4移行ガイド.md) |
| ビルドや実行時の問題を直したい | [トラブルシューティング](reference/トラブルシューティング.md) |
