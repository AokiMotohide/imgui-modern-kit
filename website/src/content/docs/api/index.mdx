## APIを探す

ImKitの公開ヘッダーにある宣言と、使うときに大事な契約をまとめています。署名と条件の一次資料は、各公開ヘッダーです。

- [Node Editor API](./node-editor/): `BeginEditor`の呼び出し例、戻り値、寿命、対になる終了の呼び出し。
- [Dear ImGui native API](./native/): `<imkit/native.h>`が公開する、`included: true`の宣言。ホストのライフサイクルやデバッグのAPIは除きます。
- [Editor SuiteのAPI](./editor-suite/): 選択、キャンバス、タイムライン、ビデオ、CGの契約。
- [Design-system API](./design-system/): ヘッダーと型の一覧です。関数の署名をすべて並べたものではありません。
- [WindowFrame API](./window-frame/): 型と関数の名前、任意のプラットフォームのターゲット。署名はヘッダーを参照してください。
- [部品一覧](./widgets/): 公開コンポーネントの一覧。
