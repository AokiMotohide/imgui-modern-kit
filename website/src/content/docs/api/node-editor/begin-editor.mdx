## 宣言

`<imkit/node_editor.h>`の`imkit::node_editor`名前空間で宣言されています。

```cpp
namespace imkit::node_editor {
EditorFrame BeginEditor(const char *id, GraphView graph, EditorState &state,
                        RequestBuffer &requests, const NodeStyle &style,
                        EditorOptions options = {});
}
```

この宣言は、公開ヘッダーと、`docs/node-editor-api.json`の`imkit::node_editor::BeginEditor`の項目に一致します。

## 引数

| 引数 | 型 | 意味と扱い |
|---|---|---|
| `id` | `const char*` | 現在のImGuiのID範囲で、このエディタの領域を識別する文字列です。呼び出しの間だけ読まれます。 |
| `graph` | `GraphView` | グラフのIDとrevision、ノード、ピン、リンクのビュー、コールバックを持つ値です。spanとコールバックの参照先は借用です。 |
| `state` | `EditorState&` | 選択、カメラ、操作の状態を持つ、アプリ所有の状態です。同じエディタと同じContextで、フレームをまたいで使い回します。 |
| `requests` | `RequestBuffer&` | UIの編集を書き込む、容量が決まったアプリ所有のバッファーです。アプリが読み取って検証してから、クリアします。 |
| `style` | `const NodeStyle&` | このフレームのスタイルです。返される`EditorFrame`にコピーされます。 |
| `options` | `EditorOptions` | 大きさ、グリッド、スナップ、ミニマップ、読み取り専用などの設定です。省略すると、メンバーの既定値を使います。 |

## 戻り値

`EditorFrame`を値で返します。描画する前に`visible`を確かめ、このハンドルを`DrawLinks`、`DrawNodes`、`NodePalette`などに渡します。`graph`、`style`、`options`はハンドルの中に保存され、`state`と`requests`は、呼び出し元を指す、所有しないポインターです。ハンドルは、同じContextの同じフレームの中で使い終えます。保存したり、別のContextへ移したりしないでください。

## 最小の呼び出し

```cpp
#include <imkit/node_editor.h>

namespace ne = imkit::node_editor;

void DrawGraph(ne::GraphView graph, ne::EditorState& state,
               ne::RequestBuffer& requests, const ne::NodeStyle& style) {
    auto frame = ne::BeginEditor("material-graph", graph, state, requests, style);
    ne::DrawLinks(frame); // 接続線の描画を予約する。実際の描画は、行のあと、EndEditorで行う
    if (frame.visible) {
        ne::DrawNodes(frame);
    }
    ne::EndEditor(frame);
}
```

`graph`、`state`、`requests`、`style`は、アプリが用意し、この関数は、アプリの有効なDear ImGuiのフレームの中で呼びます。

<Aside type="caution" title="対になる呼び出し">
`EndEditor(frame)`は、`frame.visible == false`のときも必ず呼びます。`BeginNode(frame, id)`を直接使うときは、その戻り値がtrueのときだけ、`EndNode(frame)`を呼びます。
</Aside>

## 所有と寿命

`BeginEditor`は、Dear ImGuiのContextを初期化せず、グラフのモデルも持ちません。`GraphView`が参照するspan、文字列、コールバック、`user`のデータ、スタイルの領域は、借用です。少なくとも`EndEditor`までは有効に保ってください。`NodeInspector`や`DrawDetachedPreviews`が同じビューを使うときは、それらの呼び出しが終わるまで保ちます。コールバックの中で、参照している領域を再確保してはいけません。

`EditorState`は、アプリが持ち、同じ有効なContext上のエディタに、フレームをまたいで渡します。`RequestBuffer`は、渡されたspanの容量の範囲でだけ、書き込みます。操作の一部だけを適用してはいけません。グラフのIDとrevisionを照合し、操作は、1つずつ、全体を受け入れるか、拒否します。

## 範囲

`BeginEditor`の呼び出しがコンパイルできても、アプリのグラフのモデル、Undo、OSのネイティブ入力とIME、DPI、インストール済みのSDKの動作は、確かめられません。これらは、アプリ、または別の検証の範囲です。返った要求を適用する、完全なモデルの作り方は、[ノードエディタを作る](../../../tutorials/node-editor/)にあります。
