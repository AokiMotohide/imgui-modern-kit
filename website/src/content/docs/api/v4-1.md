4.1で公開APIに加わったものと、その置き場所をまとめます。どれも描画の呼び出しか、ただの値です。状態、テクスチャ、寿命はアプリが持ち、返ってきた要求もアプリが処理します。公開構造体は末尾にメンバーが加わったので、アプリと、リンクするすべてのImKitライブラリを、4.1のヘッダーで再ビルドしてください。ノードエディタを除き、既定値は変わりません。詳しくは[4.0から4.1へ](../../platform/migration-v4/#40から41へ)を参照してください。

## どこにあるか

| ヘッダー | CMakeターゲット | 追加するもの | Galleryの画面 |
| --- | --- | --- | --- |
| `imkit/show/led.h` | `imkit::show` | `TileMap`: タイル状の表示装置のパネル1枚を1マスとして描き、ポートや電源回路ごとに色分けする | LED |
| `imkit/theme.h` | `imkit::imkit` | `Theme::layout`（`LayoutTokens`）: コントロールの縦幅を決める寸法。`Theme::node`（`NodeTokens`） | Node Editor Gallery |
| `imkit/decor.h` | `imkit::imkit` | `Sprite`、`SpriteSheet`、`SpriteState`、`SpriteFrameAt`、`SpriteFrameUV`、`DrawSprite` | Skins |

| `imkit/node_editor.h` | `imkit::node_editor` | ヘッダーの塗り、配線の色と矢印、ソケットの記号、ノードの形と状態、プリセット、描画フック、パネル、配線中のフィードバック、新しい操作 | Node Editor Gallery |

## タイル状の表示装置のタイルマップ

`show::TileMap` は、LEDウォールのキャビネットのようなタイル状の表示装置を、パネル1枚を1マスとして描きます。マスはグループ（そのパネルへ給電・送信するデータポートや電源回路）ごとに色分けし、グループ内を `order` の順に線で結んでケーブルの順序を示します。先頭のマスには点を打ちます。`highlightGroup` を指定すると、ほかのグループを薄く表示します。ホストは、ポインタが乗ったマスとクリックしたマスを受け取り、ツールチップを自分で描きます。

```cpp
#include <imkit/show.h>

const std::array<imkit::show::TileMapTile, 4> tiles{{
    {.column = 0, .row = 0, .group = 0, .order = 0, .label = "1-1"},
    {.column = 1, .row = 0, .group = 0, .order = 1, .label = "1-2"},
    {.column = 0, .row = 1, .group = 1, .order = 0, .label = "2-1"},
    {.column = 1, .row = 1, .group = 1, .order = 1, .label = "2-2", .missing = true},
}};
static int selected = -1;

imkit::show::TileMapOptions options;
options.highlightGroup = 0;                          // ほかのポートを薄くする
const auto request = imkit::show::TileMap("wall", {.columns = 2, .rows = 2, .tiles = tiles}, &selected, options);
if (request.hovered >= 0) ImGui::SetTooltip("Port %d", tiles[request.hovered].group + 1);
```

## 調整できるコントロールの寸法

`Theme::layout` で、コントロールの縦幅を決める寸法を上書きできます。未指定の項目は密度の値のままなので、既存のテーマの見た目は変わりません。`ResolveTheme` が密度のあとに適用するので、トークンを変えたら呼んでください。

```cpp
auto theme = imkit::MakeTheme(imkit::ThemePreset::Graphite);
theme.layout.controlHeight = 34.f;     // コントロールを高くする
theme.layout.spacingY = 6.f;
theme.layout.checkHeightScale = 1.6f;  // チェックボックスの高さ。文字サイズに対する倍率
imkit::ResolveTheme(theme);
imkit::ApplyTheme(theme, 1.0f);
```

| 区分 | トークン |
| --- | --- |
| 長さ（画面のピクセル） | `controlHeight`、`spacingX`、`spacingY`、`horizontalPadding`、`windowPaddingX`、`windowPaddingY`、`cellPaddingY`、`indent`、`scrollbar`、`grabMin`、`separatorTextPaddingY` |
| 部品ごとの比率 | `checkHeightScale`、`toggleHeightScale`、`dialogPaddingScale`、`progressBarHeightScale`、`badgeExtraHeight`、`segmentedInset` |

`Metrics` に解決済みの値（`spacingY`、`windowPaddingX/Y`、`cellPaddingY`、`indent`、`scrollbar`、`grabMin`、`separatorTextPaddingY`、`parts`）が加わります。`Theme` を持たない部品（Checkbox、Toggle、StatusBadge、Segmented、ダイアログ、進捗バー）は、そのコンテキストに最後に適用したテーマの `parts` を読みます。`ThemeScope` は前の値に戻します。テーマファイルでは `layout.*` キーを読み書きでき（[テーマファイルのキー](../../features/make-your-own-look/)を参照）、未指定のトークンは書き出しません。

## スプライトと進捗のつまみ

`Sprite` は、ホストが読み込んで所有する1枚のテクスチャに並べた、同じ大きさのコマのシートを再生します。`Loop`、`Once`（終わったら静止コマ）、`HoldLast` に対応します。`reducedMotion` では `restFrame` を表示し、見えない領域は描きません。

```cpp
imkit::SpriteSheet ball;
ball.texture = ballTexture;                       // ホストが所有する
ball.sheetPixels = {256, 192};
ball.cellPixels = {64, 64};
ball.columns = 4;
ball.frames = 12;
ball.fps = 24.f;
static imkit::SpriteState state;
const bool animate = theme.motion.enabled && !theme.motion.reducedMotion;
imkit::Sprite("ball", ball, state, ImGui::GetTime(), {64, 64}, animate);
```

`SpriteFrameAt` と `SpriteFrameUV` は、Dear ImGui のコンテキストなしで、コマ番号とテクスチャ座標を返します。`DrawSprite` は、任意の矩形に1コマを描きます。

`ProgressTrackView::thumb` は、トラックの矩形、先頭の位置、表示中の割合をホストへ渡し、塗りに乗る絵を描けるようにします。確定した進捗と、動いている不確定の進捗で呼ばれます。`thumbHeight` は、トラックの上にレイアウトの高さを確保し、絵が見出しに重ならないようにします。

## カメラが持つ機能だけを描くPTZ操作

`PtzView::capabilities` で、カメラが持たない操作を隠せます。パンだけの雲台、ズームだけのレンズ、呼び出し専用のプリセットでは小さな操作部になり、何もなければ1行の文だけを描きます。どのフィールドも既定値はtrueなので、既存のコードは変わりません。

```cpp
imkit::PtzView view;
view.capabilities.tilt = false;        // パンだけの雲台
view.capabilities.presetStore = false; // プリセットは呼び出せるが、登録はできない
view.readoutText.pan = "+0.35";        // 正規化した値を報告する機器向け
const auto request = imkit::PtzControl("camera", view, state);
```

直径が既定のときは、狭い配置先でも右端が切れないよう、パッドをフレーム高さの3.2倍まで縮めます。ロケールキー `ptz.panPad`、`ptz.tiltPad`、`ptz.presetRecallHint`、`ptz.unsupported` を追加しました。詳しくは[PTZ操作の文書](../../features/ptz/)を参照してください。

## ノードエディタ

ノードエディタは、新しい既定の見た目と、それを組み立てる部品を備えます。全体は[ノードエディタ](../../features/node-editor/)を参照してください。

| 領域 | 追加するもの |
| --- | --- |
| 見た目 | `NodeStyle::headerFill`（`Strip`、`Tinted`、`Flat`、`Gradient`、`None`）、`headerTint`、`linkColor`、`linkArrow`、`highlightConnectedLinks`、`hollowUnconnectedPins`、`status`。`NodeView::category`、`tint`、`subtitle`、`glyph`。`Theme::node` と `node.*` のテーマキー |
| プリセットとフック | `MakeNodeStylePreset`（`Classic`、`Studio`、`Logic`）。`NodeStyle::hooks`（`NodeDrawHooks`）で、背景、タイトル行、ソケット、配線の描画を置き換える |
| ソケット | `PinView::role`、`container`、`flags`、`keyType`、`inspect`、`reason`。`DrawPinGlyph`、`PinChromeView`。Flowの配線、長円の入力、`pinSeat` |
| 配線中のフィードバック | 候補の輪、受けられないソケットとノードを薄く、吸着、判定のピル。既存の配線には `LinkView::validity` と `reason` |
| 形と状態 | `NodeView::shape`、`diagnostic`。Frame、Group、Note、サブグラフのカード。実行中、待機、成功、エラー、Bypass、無効、キャッシュ、ブレークポイント、ロックの各状態 |
| パネル | `BeginNodePanel`、`EndNodePanel`、`NodeView::hideUnusedPins` |
| 操作 | Altクリックでソケットの配線を外し、Ctrlドラッグ（macOSではCmd）で別のソケットへ移します。配線のダブルクリックで `EditKind::InsertReroute` を要求。`ConnectSelected`。`Keymap::bypass`（Ctrl+B）と `collapse`（Ctrl+H） |
| ローカライズ | `EditorOptions::locale`。`EditorFrame::hoveredNode` |

## 所有の分担

| ImKitがすること | アプリが持つもの |
| --- | --- |
| タイルマップを描き、ポインタが乗ったマスとクリックしたマスを返す | タイル、ポートの割り当て、ツールチップ |
| コマの計算にもとづいてスプライトを再生する | テクスチャ、その寿命、時計 |
| 機能が許す範囲のPTZ操作だけを描く | カメラと、その報告 |
| 渡されたテーマにレイアウトトークンを適用する | テーマファイルとその寿命 |
