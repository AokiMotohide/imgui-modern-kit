4.2で公開APIに加わった機能と、その置き場所をまとめます。どれも即時モードの描画呼び出しか、ただの値型です。Dear ImGuiのContext、GPUレンダラー、フォント、状態、寿命はアプリが所有し、返された操作要求もアプリが処理します。公開構造体の末尾にメンバーが増えているため、アプリとリンクするすべてのImKitライブラリを4.2のヘッダーで再ビルドしてください。手順は[4.1から4.2へ](../../platform/migration-v4/#41から42へ)を参照してください。

## 4層カスタマイズ基盤と22部品の刷新

ImKit 4.2では、22種類の基本部品（`Part::Button`〜`Modal`）を、連続曲率の滑らかな角丸（`DrawSmoothRect`）とコントロール高さ比例の角半径（`Radius::controlShare = 0.25f`）で刷新しました。テーマファイルから独自描画まで4つの層で自在に上書きできます。

```cpp
#include <imkit/imkit.h>

// L1: Theme::partOverrides 上のテーマテキストキー
// button.hover.fill = accent
// slider.thumb.size = 14

// L2: 型付きの単発スタイル、または名前登録＋StyleScope
imkit::ButtonStyle danger;
danger.colors.hover.fill = imkit::Hex("#c83745");
imkit::RegisterStyle("danger", danger);

{
    imkit::StyleScope scope("danger");
    imkit::ActionButton("Delete", imkit::ActionVariant::Secondary);
}

// 単発の呼び出し引数は、スコープやテーマキーより優先されます
imkit::Button("Confirm", {}, danger);
```

- **優先順位（強い順）:** 単発呼び出しの型付きスタイル（`ButtonStyle`、`SliderStyle` など）→ `PushPartVar` / `PushPartColor`（および `ImGui::PushStyleVar` / `PushStyleColor`）→ 名前付き `StyleScope` → L1 テーマテキスト → ImKit モダン既定値。
- **L3（`Skin`）と L4（`Interact`）:** `SkinFrame`（`Skin`）はレイアウトと当たり判定を保ったまま枠描画だけを差し替えます。`Interact()` は任意の矩形を登録してイージング済みの `hover01` / `active01` / `focus01` を返し、ImKit 部品と同じ描画ヘルパー（`DrawSmoothRect`、`DrawSmoothRectBorder`、`DrawDashedRect`、`DrawSoftShadow`、`DrawFocusRing`、`DrawChevron`、`DrawCheckMark`）で独自部品を作れます。
- **対話型インスペクター:** `ShowStyleEditor(&theme, &open)` で、解決済みの値と適用元の層（`PartLayer`）をリアルタイムに確認・調整できます。
- **Classic プリセット:** 14個目の内蔵テーマ `ThemePreset::Classic`（`ThemeLook::Classic`）を選ぶと、4.1 の標準的な Dear ImGui の形状のまま OKLCH サーフェスやエディタ機能を使えます。

## ビューポートのグロー枠と外部制御インジケーター

`DrawGlowFrame` は矩形の縁に沿って、点灯・呼吸・周回の光と波紋を描画します。これを活用する `ExternalControlIndicator` は、自動化 API、遠隔の操作者、AI エージェントがアプリを操作している間にビューポート外周を光で囲み、クライアント名・作業内容・停止ボタンを表示するピル（`OverlayAnchor`）を重ねます。

```cpp
#include <imkit/imkit.h>

static imkit::ExternalControlState extState;
imkit::ExternalControlView extView;
extView.phase = imkit::ExternalControlPhase::Active;
extView.clientName = "agent-client";
extView.activity = "Adjusting colour balance";
extView.canStop = true;

auto req = imkit::ExternalControlIndicator(extView, extState, ImGui::GetIO().DeltaTime);
if (req.stopRequested) {
    host.CancelRemoteSession();
}
```

- 状態遷移は滑らかに補間（`transitionSeconds`）され、ホストが段階を下げたあとも `holdSeconds` の間保持し、`pulseInterval` 内の連続パルスを1つの波紋に統合します。
- `pillFill = ExternalControlPillFill::Surface` を指定すると、不透明度 96% の浮いたサーフェスと 4.5:1 の文字コントラストで描画され、背後に映像が流れていても文字が埋もれません。

## 面の役割（SurfaceZone）とウィンドウの役割（WindowRole）

`ResolveTheme` が OKLCH 明度に基づいて `SurfaceZone`（`Chrome`、`Panel`、`Workspace`、`Monitor`、`Inspector`、`Header`、`ChromeCanvas`）を均等な段差で算出し、ドッキングした各ウィンドウに役割色（`WindowRole::Browse`、`Edit`、`View`、`Monitor`）を与えます。

```cpp
imkit::PushWindowRole(theme, imkit::WindowRole::Edit);
if (imkit::Begin("Inspector")) {
    imkit::DockTabBand(theme, imkit::WindowRole::Edit);
    imkit::PushFloatingPanel(theme);
    imkit::PopFloatingPanel();
}
imkit::End();
imkit::PopWindowRole();
```

## Workflow・曲線・タイムラインの追加

- **`StepBand` と `DrawPlateMark`:** 工程群を淡く色分けしたトレイに1行で並べる工程帯。番号つきプレート（`PlateGrowth`、寄り道の点線ルート、前提不足・草の装飾 `PlateMarkDecor`）で進捗と状態を示します。
- **`TransferCurveEditor` と `TransferCurveSectionEditor`:** 複数系列、表示単位マッピング、ハンドル操作、キーボード微調整、縦横の断面表示切替を備えた 3 次ベジェ伝達曲線エディターです。
- **`SliderFloatWithInput` と `TextRole::Numeric`:** スライダーと `FontSet::numeric` を使った数値入力を1行に並べ、ドラッグ中の値と確定した変更を分けて返します。
- **タイムラインのコマ表示と背景固定:** `TimelineOptions::clipBody = ClipBody::Filmstrip` で `TimelineProvider::thumbnailAt` の 16:9 サムネイルをクリップ上に並べます。`BackdropStyle::phase` と `scale` で、パン・ズームするキャンバスに背景パターンを固定できます。

## Dear ImGui 非依存ターゲット `imkit::motion`

`imkit::motion`（`<imkit/easing.h>`、`<imkit/motion_curve.h>`）は、イージング曲線（`EaseIn`、`OutBack`、`InBack`、`Spring`、`EvaluateMotionEase`）と CSS 準拠キーフレーム評価（`MotionKey`、`EvaluateMotionTrack`、`WrapMotionTime`）を Dear ImGui なしで提供します。GUI を持たないバックエンドやメディアサーバー、シミュレーターからも単独でリンクできます。`imkit::imkit` は自動的にこれをリンクし、`DrawLayeredMotion` を提供します。

## 所有の分担

| ImKitがすること | アプリが持つもの |
| --- | --- |
| 4つのスタイル層を解決し、滑らかな角で22部品を描画する | ウィジェットの値、登録スタイルの名前、テーマファイル |
| 縁のグローを描き、ピル上の停止ボタンの押下要求を返す | 遠隔・自動化セッション、入力ロック方針、キャンセル実行 |
| 伝達曲線、キーフレーム軌道、フィルムストリップ配置を計算する | 曲線データ、時刻、サムネイル画像とGPUテクスチャ |
| OKLCH で面・役割の配色を導出し、ドッキングタブ帯を塗る | Dear ImGui の Context、レンダラー、フォント、Undo 履歴 |
