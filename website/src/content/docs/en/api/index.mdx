## Find an API

This section maps declarations in the public ImKit headers and explains contracts that matter when calling them. Use each public header as the source of truth for exact signatures and conditions.

- [Node Editor API](./node-editor/) — includes the `BeginEditor` call example, return value, lifetimes, and paired calls.
- [Dear ImGui native API](./native/) — declarations marked `included: true` from `<imkit/native.h>`; host lifecycle and debug APIs are omitted.
- [Editor Suite API contracts](./editor-suite/) — contract references for selection, canvas, timeline, video, and CG surfaces.
- [Design-system header map](./design-system/) — header/type metadata, not a complete function-signature inventory.
- [WindowFrame API map](./window-frame/) — type and function names plus optional platform targets; consult the header for signatures.
- [Component inventory](./widgets/) — route into the public component inventory.
