## Find an API

This section collects the declarations in ImKit's public headers and the contracts that matter when you call them. The primary source for signatures and conditions is each public header.

- [Node Editor API](./node-editor/): the `BeginEditor` call, its return value, lifetime and the paired end call.
- [Dear ImGui native API](./native/): the `included: true` declarations that `<imkit/native.h>` exposes. Host lifecycle and debug APIs are left out.
- [Editor Suite API](./editor-suite/): contracts for selection, canvas, timeline, video and CG.
- [Design-system API](./design-system/): the headers and types. It is not a full list of function signatures.
- [WindowFrame API](./window-frame/): type and function names and the optional platform targets. See the header for signatures.
- [Component inventory](./widgets/): the list of public components.
