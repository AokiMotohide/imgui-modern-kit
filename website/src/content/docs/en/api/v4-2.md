This page summarises what ImKit 4.2 adds to the public API and where each piece lives. Every entry is an immediate-mode draw call or a plain value type: the application keeps context, GPU renderer, fonts, state and lifetime, and handles any returned requests. Public structures grew at their end, so rebuild your application and every linked ImKit library with the 4.2 headers; see [Upgrading from 4.1 to 4.2](../../platform/migration-v4/#upgrading-from-41-to-42).

## Four-layer customisation and 22 rebuilt parts

ImKit 4.2 replaces stock Dear ImGui control shapes across 22 `Part` entries (`Button` through `Modal`) with smooth continuous-curvature geometry (`DrawSmoothRect`) and proportional corners (`Radius::controlShare = 0.25f`). Four layers override any part cleanly, from theme files down to custom draw calls:

```cpp
#include <imkit/imkit.h>

// L1: Theme text override on Theme::partOverrides
// button.hover.fill = accent
// slider.thumb.size = 14

// L2: Typed per-call or scoped style
imkit::ButtonStyle danger;
danger.colors.hover.fill = imkit::Hex("#c83745");
imkit::RegisterStyle("danger", danger);

{
    imkit::StyleScope scope("danger");
    imkit::ActionButton("Delete", imkit::ActionVariant::Secondary);
}

// One-call override takes priority over scopes and theme keys
imkit::Button("Confirm", {}, danger);
```

- **Precedence (strongest first):** one-call typed style (`ButtonStyle`, `SliderStyle`, ...) → `PushPartVar` / `PushPartColor` (or Dear ImGui `PushStyleVar` / `PushStyleColor`) → named `StyleScope` → L1 theme text keys → ImKit modern defaults.
- **L3 (`Skin`) and L4 (`Interact`):** `SkinFrame` (`Skin`) replaces frame drawing while keeping layout and hit-testing; `Interact()` registers an arbitrary hit rectangle and returns eased `hover01` / `active01` / `focus01` state alongside helpers (`DrawSmoothRect`, `DrawSmoothRectBorder`, `DrawDashedRect`, `DrawSoftShadow`, `DrawFocusRing`, `DrawChevron`, `DrawCheckMark`).
- **Interactive inspector:** `ShowStyleEditor(&theme, &open)` inspects live resolved values and which `PartLayer` supplied each one.
- **Classic preset:** `ThemePreset::Classic` (14th built-in preset, `ThemeLook::Classic`) restores 4.1 Dear ImGui shapes whenever desired, without sacrificing OKLCH surfaces or editor features.

## Viewport glow and external control indicator

`DrawGlowFrame` draws a steady, breathing or orbiting glow around any rectangle with ripple pulses. Built on top of it, `ExternalControlIndicator` surrounds an application viewport while an automation client, remote operator or AI agent drives the app, paired with a compact floating pill (`OverlayAnchor`).

```cpp
#include <imkit/imkit.h>

static imkit::ExternalControlState extState;
imkit::ExternalControlView extView;
extView.phase = imkit::ExternalControlPhase::Active;
extView.clientName = "agent-client";
extView.activity = "Adjusting colour balance";
extView.canStop = true;

auto req = imkit::ExternalControlIndicator(extView, extState, ImGui::GetIO().DeltaTime);
if (req.stopRequested) {
    host.CancelRemoteSession();
}
```

- Phase transitions blend smoothly (`transitionSeconds`), hold after the host lowers a phase (`holdSeconds`), and coalesce bursts within `pulseInterval` into a single edge ripple.
- When `pillFill = ExternalControlPillFill::Surface`, the pill paints a 96%-opaque raised theme surface with 4.5:1 text contrast so bright video footage underneath stays readable.

## Surface zones and window roles

`ResolveTheme` steps `SurfaceZone` (`Chrome`, `Panel`, `Workspace`, `Monitor`, `Inspector`, `Header`, `ChromeCanvas`) evenly in OKLCH lightness and assigns per-role colours for docked windows (`WindowRole::Browse`, `Edit`, `View`, `Monitor`):

```cpp
imkit::PushWindowRole(theme, imkit::WindowRole::Edit);
if (imkit::Begin("Inspector")) {
    imkit::DockTabBand(theme, imkit::WindowRole::Edit);
    imkit::PushFloatingPanel(theme);
    imkit::PopFloatingPanel();
}
imkit::End();
imkit::PopWindowRole();
```

## Workflow, curves and timeline additions

- **`StepBand` and `DrawPlateMark`:** Single-row stage pipeline grouped into tinted trays, with numbered marks whose geometry conveys state (`PlateGrowth`, optional dotted routes, and blocking/grass details via `PlateMarkDecor`).
- **`TransferCurveEditor` & `TransferCurveSectionEditor`:** Cubic Bezier curve editing with multi-series support, display-unit mapping, knot/handle dragging, keyboard stepping, and optional vertical/horizontal cross-section views.
- **`SliderFloatWithInput` & `TextRole::Numeric`:** Combines a slider and aligned numeric readout in `FontSet::numeric` on one row, returning live drag and committed edits separately.
- **Timeline filmstrips & anchored backdrops:** `TimelineOptions::clipBody = ClipBody::Filmstrip` renders 16:9 clip thumbnails from `TimelineProvider::thumbnailAt`; `BackdropStyle::phase` and `scale` anchor patterns to panned/zoomed canvases.

## Standalone `imkit::motion` target

`imkit::motion` (`<imkit/easing.h>`, `<imkit/motion_curve.h>`) contains easing curves (`EaseIn`, `OutBack`, `InBack`, `Spring`, `EvaluateMotionEase`) and CSS-ordered keyframe track evaluation (`MotionKey`, `EvaluateMotionTrack`, `WrapMotionTime`) with zero dependency on Dear ImGui. Non-UI services, media servers or simulators can link `imkit::motion` alone; `imkit::imkit` links it automatically and adds `DrawLayeredMotion`.

## Ownership

| ImKit does | Your application keeps |
| --- | --- |
| Resolves the 4 style layers and draws 22 smooth-cornered parts | Widget values, registered style names and theme files |
| Renders the edge glow and returns Stop clicks from the indicator pill | Remote/automation sessions, locking policy and cancellation |
| Evaluates Bezier curves, keyframe tracks and filmstrip geometry | Curve data, timestamps, thumbnail images and textures |
| Derives OKLCH zone/role palettes and draws docked tab bands | Dear ImGui context, renderer, fonts and undo stack |
