## Add it to your application

ImKit does not create a context, backend, renderer, or font atlas. Call the modules you need from your Dear ImGui application. Controls work with host values; editor surfaces borrow views and return bounded requests.

<div class="home-points">
  <div><span class="point-index">01</span><strong>Choose the modules</strong><p>Select Theme, workflow, Editor Suite, or Node Editor as separate targets.</p></div>
  <div><span class="point-index">02</span><strong>Keep data ownership</strong><p>Controls work with host values. Editor surfaces borrow views and return bounded requests; the model stays with the host.</p></div>
  <div><span class="point-index">03</span><strong>Work with native ImGui</strong><p>Combine public widgets with ordinary ImGui input in the frame your host begins.</p></div>
</div>
