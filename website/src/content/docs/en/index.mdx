## New in 4.0: make the look yours, reach the stage

A refreshed default look, brand themes built from four colours, skins, charts, PTZ control, and the `show` module for media servers. Rebuild with the 4.0 headers: see the [4.0 additions](./api/v4-0/) and the [migration guide](./platform/migration-v4/).

[v4.0.0 SDK](https://github.com/AokiMotohide/imgui-modern-kit/releases/tag/v4.0.0)

The film above (about three minutes) shows these features in use.

## Add it to your application

ImKit does not create a context, backend, renderer, or font atlas. Call the modules you need from your Dear ImGui application. Controls work with host values; editor surfaces borrow views and return bounded requests.

<div class="home-points">
  <div><span class="point-index">01</span><strong>Choose the modules</strong><p>Select Theme, Workflow, Editor Suite, Node Editor or Show as separate targets.</p></div>
  <div><span class="point-index">02</span><strong>Keep data ownership</strong><p>Controls work with host values. Editor surfaces borrow views and return bounded requests; the model stays with the host.</p></div>
